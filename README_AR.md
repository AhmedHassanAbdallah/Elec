# تطبيق حسابات وفواتير أعمال الكهرباء (م. أحمد حسن)

يحتوي هذا المجلد على:
1. ملف التطبيق الكامل الجاهز للعمل فوراً على الموبايل (`app/src/main/assets/index.html`).
2. مشروع أندرويد المتكامل (`Android Studio / Gradle`) + ملف بناء سحابي تلقائي (`.github/workflows/build-apk.yml`) لاستخراج ملف `Electrical-Billing-App.apk`.

## طرق التثبيت السريع على هاتفك:
1. **تثبيت فوري بدون برامج (PWA)**: افتح ملف `electrical_billing_app.html` في متصفح Chrome على هاتفك واضغط **تثبيت التطبيق (Install App / الإضافة إلى الشاشة الرئيسية)** ليعمل كتطبيق مستقل بدون إنترنت.
2. **تحويل مباشر إلى APK من الهاتف**: افتح تطبيق **Website 2 APK** أو **WebCode** واختر ملف `index.html` ليخرج لك ملف `.apk` في ثوانٍ.
3. **بناء APK عبر GitHub Actions مجاناً بدون كمبيوتر**: ارفع هذا المجلد إلى مستودع GitHub وستجد ملف `app-debug.apk` جاهزاً للتحميل في قسم `Actions`.
